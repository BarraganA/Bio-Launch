# Neural Gate Lab

Aplicación web para explorar una neurona artificial con función de activación escalón.

## Estructura

```text
neural_gate_lab/
├── index.html
├── style.css
└── script.js
```

## Publicar en GitHub Pages

1. Crea una carpeta dentro de tu repositorio, por ejemplo:
   `neural_gate_lab/`
2. Sube los tres archivos a esa carpeta.
3. Mantén los nombres exactamente como:
   - `index.html`
   - `style.css`
   - `script.js`
4. Si GitHub Pages está habilitado, la app estará disponible en:
   `https://TU_USUARIO.github.io/TU_REPOSITORIO/neural_gate_lab/`

## Canvas

Cuando tengas la URL pública:

```html
<iframe
  src="https://TU_USUARIO.github.io/TU_REPOSITORIO/neural_gate_lab/"
  width="100%"
  height="760"
  style="border:0;"
  loading="lazy">
</iframe>
```

La aplicación no identifica ni evalúa compuertas lógicas. Canvas proporciona las instrucciones y la app funciona sólo como instrumento de exploración.
